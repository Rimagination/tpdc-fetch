# Example: 1:100,000 desert (sand) distribution dataset

Dataset: **中国1:10万沙漠(沙地)分布数据集**
ID: `122c9ac2-53ee-4b9a-ae87-1a980b131c9b`
DOI: `10.3972/westdc.006.2013.db`
Access: **A** (open, no login)
Files: 146, about 1.54 GB
Top-level directory: `1：10万沙漠分布图` (full-width colon)

## Search

```bash
python scripts/tpdc.py search "1:10万沙漠" --limit 5
```

Expected row:

```text
122c9ac2-53ee-4b9a-ae87-1a980b131c9b   A   中国1:10万沙漠(沙地)分布数据集   王建华,王一谋,颜长珍,祁元   10.3972/westdc.006.2013.db
```

## Inspect

python scripts/tpdc.py files 122c9ac2-53ee-4b9a-ae87-1a980b131c9b

## Dry run

```bash
python scripts/tpdc.py download 122c9ac2-53ee-4b9a-ae87-1a980b131c9b \
  --out ./desert_1_100000 --dry-run
```

Expected:

```text
数据集: 122c9ac2-53ee-4b9a-ae87-1a980b131c9b
访问: A 类  |  FTP: ftp2.tpdc.ac.cn, ftp3.tpdc.ac.cn:6201

```

## Download

```bash
python scripts/tpdc.py download 122c9ac2-53ee-4b9a-ae87-1a980b131c9b \
  --out ./desert_1_100000 --workers 4
```

Resume after an interruption:

```bash
python scripts/tpdc.py download 122c9ac2-53ee-4b9a-ae87-1a980b131c9b \
  --out ./desert_1_100000 --workers 4
```

Only the national layer and its sidecars:

```bash
python scripts/tpdc.py download 122c9ac2-53ee-4b9a-ae87-1a980b131c9b \
  --out ./desert_1_100000 \
  --include "*/desert.shp" --include "*/desert.dbf" --include "*/desert.shx" --include "*/desert.shp.xml"
```

## Outputs

```text
desert_1_100000/
├── 1：10万沙漠分布图/
│   ├── desert.shp
│   ├── desert.dbf
│   ├── ...
├── manifest.json
└── CITATION.txt
```

`manifest.json` records the dataset ID, DOI, access policy, FTP host, download time,
and per-file sizes. `CITATION.txt` contains a ready-to-paste citation.

## Notes

- `ftp2` is often full; the script falls back to `ftp3` automatically.
- TPDC allows 5 connections per IP; keep `--workers 4`.
- Daytime downloads are slow; 02:00–10:00 local time is usually much faster.
- The full-width colon in `1：10万沙漠分布图` is part of the remote path and is
  preserved locally; do not rename it if you want to resume.
